# Known Trap: Share Link Expiry

## Overview
This page documents share link expiration policies to prevent confusion when customers report broken links.

## Current Policy
- Details to be documented from product specifications

## Common Issues
- Share links may expire after a certain period
- Customers may not realize links have expiration dates
- Different link types may have different expiry rules

## How to Handle
- Verify the link creation date
- Check if link type has expiration enabled
- Explain expiry policy to customer
- Help generate new link if needed
